Painel de Demonstração Acadêmica SGBD (MySQL 8)

Área de Validação de Requisitos Acadêmicos: Permite demonstrar em tempo real todos os recursos obrigatórios de SGBD (TCL: COMMIT/ROLLBACK, Views, Stored Procedures, Functions, Triggers, Índices com EXPLAIN e Permissões sem ROOT).
1. Transações TCL (COMMIT e ROLLBACK)
Aguardando comando de demonstração transacional... Clique em um dos botões acima para iniciar o teste no MySQL.
2. Views do SGBD MySQL
Selecione uma das Views acima para visualizar os dados retornados pelo MySQL.
3. Stored Functions de Regra de Negócio
Clique no botão para executar fn_gerar_id_aluno, fn_gerar_id_matricula, fn_calcular_saldo_mensalidade e fn_verificar_situacao_mensalidade.
4. Triggers Automáticas & Auditoria
Clique para visualizar registros criados automaticamente pela Trigger trg_pagamento_after_insert_auditoria.
5. Análise de Índices com EXPLAIN
Demonstração do plano de execução do otimizador de consultas do MySQL utilizando os índices B-Tree criados.
6. Segurança e Conexão sem ROOT
Clique para comprovar que a aplicação conecta exclusivamente através do usuário restrito academia_app.
